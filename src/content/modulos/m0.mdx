## Essencial

### O que é: um agente, não um chat com sotaque de programador

Num chat, você pergunta e recebe texto. Copiar, colar, rodar e conferir ficam por sua conta. O Claude Code inverte isso: ele trabalha **dentro da sua pasta** e faz o serviço completo.

Cada tarefa passa por um ciclo de três fases, repetido até acabar:

1. **Coletar contexto.** Procura e lê os arquivos que importam.
2. **Agir.** Edita arquivos, cria outros, roda comandos.
3. **Verificar.** Executa testes, lê o erro, corrige e tenta de novo.

Esse ciclo é o **laço agêntico**. Quem raciocina é o modelo (o Claude). Quem dá mãos ao modelo é o Claude Code: as **ferramentas** para ler, editar, buscar, executar e consultar a web, mais o controle do que ele pode fazer sem perguntar.

<Nota rotulo="Não é só para código">
Serve para qualquer coisa que se faça pela linha de comando: organizar pastas, escrever documentos, tratar dados, pesquisar. O [M22](../m22/) é inteiro sobre isso.
</Nota>

Você continua no comando. Dá para interromper a qualquer momento, corrigir o rumo e desfazer edições. O [M2](../m2/) abre o motor; o [M3](../m3/) ensina a conduzir.

### Onde roda: um motor, várias portas

O motor é o mesmo em todo lugar. Muda **onde o código executa** e **como você enxerga o trabalho**.

<Nota rotulo="Nem toda porta abre com qualquer conta">
Web, celular, app desktop, Chrome e Slack pedem login com conta claude.ai. Só com chave de API, eles ficam de fora. A CLI aceita todos os tipos de conta.
</Nota>

### Chat para pensar, Claude Code para fazer

Esta é uma regra do curso, não da documentação. Ela poupa tempo e limite de uso.

| Você quer | Use |
|---|---|
| Decidir **o que** construir, comparar caminhos, rascunhar uma proposta | Chat (claude.ai ou o chat do app) |
| Escrever o escopo e a definição de pronto de um projeto | Chat, e depois salve o resultado num arquivo |
| Criar, alterar, rodar, testar, commitar, publicar | Claude Code, na pasta de trabalho |
| Entender um repositório que já existe | Claude Code: ele lê os arquivos, você não cola nada |

O sinal para trocar de ferramenta é simples. Se a próxima ação é **mexer num arquivo ou rodar um comando**, o chat acabou. Leve a decisão escrita para a pasta de trabalho e abra o Claude Code.

### O pré-requisito pago inescapável

Sem rodeio: **o Claude Code não tem acesso gratuito.** A documentação lista três tipos de conta que entram, e o plano gratuito do claude.ai não está entre eles.

| Acesso | Como você paga | Para quem |
|---|---|---|
| **Assinatura Claude** (Pro, Max, Ultra, Team ou Enterprise) | Mensalidade. O uso está incluído, até o limite do plano. | Quem está aprendendo e quem trabalha sozinho |
| **Claude Console** | Créditos pré-pagos de API. Cada sessão desconta pelo que consumiu. | Automação, CI e quem quer pagar só o que usar |
| **Provedor de nuvem** (Amazon Bedrock, Google Cloud, Microsoft Foundry) | Na conta de nuvem da empresa. | Organizações |

**Quanto custa?** Este manual não imprime preço de assinatura: ele muda, e número velho em página de curso vira armadilha. A tabela vigente fica em [claude.com/pricing](https://claude.com/pricing). Confira lá antes de assinar.

A documentação de custos publica uma média de uso **cobrado por consumo** em empresas. Serve como ordem de grandeza:

- cerca de **US$ 13 por desenvolvedor por dia ativo**;
- entre **US$ 150 e 250 por desenvolvedor por mês**;
- abaixo de **US$ 30 por dia ativo** para 90% das pessoas.

São desenvolvedores em tempo integral, pagando por token. Para seguir o curso, o caminho previsível é a assinatura: você sabe a conta antes de começar. Quando o limite do plano acaba, você espera a renovação ou liga os créditos de uso, que são cobrados à parte.

Dentro de uma sessão, `/usage` mostra quanto do plano você já gastou. O [M18](../m18/) ensina a medir e a economizar.

**E o resto?** Grátis. Hospedagem, banco, automação, canal de atendimento: cada exercício tem um caminho de custo zero. Onde o pago faz sentido, uma fita amarela **TROCA POR PAGO** diz o que trocar, quando e por quanto, com data.

### Glossário de bolso

Treze palavras que aparecem em todas as páginas. O [Apêndice A](../a/) tem a lista completa.

| Termo | Em uma frase |
|---|---|
| **Agente** | Programa que planeja os próprios passos e usa ferramentas para cumprir uma tarefa. |
| **Laço agêntico** | O ciclo coletar contexto, agir, verificar, repetido até a tarefa fechar. |
| **Modelo** | O Claude, a parte que raciocina. O Claude Code é o que fica em volta dele. |
| **Ferramenta** | Uma ação que o Claude pode executar: ler arquivo, editar, rodar comando, buscar na web. |
| **Pedido** | O que você escreve para o Claude. Em inglês, *prompt*, nome que também se dá à caixa onde você o digita. |
| **Sessão** | Uma conversa ligada a uma pasta, gravada em disco, que pode ser retomada. |
| **Janela de contexto** | A memória de trabalho da sessão: conversa, arquivos lidos, saídas de comandos. Ela enche. |
| **Token** | A unidade em que o texto é medido e cobrado. Mais contexto, mais tokens. |
| **Superfície** | Qualquer lugar por onde você usa o Claude Code: CLI, editor, app desktop, web. |
| **Modo de permissão** | A regra-base do que roda sem perguntar a você. |
| **Comando** | Instrução que começa com `/`, como `/help` ou `/clear`. A Parte II disseca todos. |
| **CLAUDE.md** | Arquivo de instruções permanentes do projeto, lido no início de cada sessão. |
| **MCP** | Padrão aberto que liga o Claude a serviços externos: GitHub, bancos, navegador. |

### Três ambientes de execução

A documentação separa a **interface** (o que você vê) do **ambiente** (onde o código roda):

- **Local.** Na sua máquina. É o padrão, com acesso total aos seus arquivos e ferramentas.
- **Nuvem.** Em máquinas virtuais gerenciadas pela Anthropic, ou em ambiente que a sua organização opera.
- **Remote Control.** Executa na sua máquina, e você dirige pelo navegador ou pelo celular.

O celular alcança os dois últimos. O app Claude não tem um "Claude Code para celular" separado: sessões na nuvem e Remote Control moram na aba **Code** do mesmo app.

### O que as portas compartilham, e o que não

As superfícies locais leem a mesma configuração, a mesma memória de projeto e os mesmos servidores MCP. Uma sessão na nuvem é diferente: parte de um clone novo do repositório e **não** lê a pasta `~/.claude` do seu computador. O que estiver só na sua máquina não viaja.

### O que cada tipo de conta alcança

A CLI, o Agent SDK e as extensões de VS Code e JetBrains funcionam com qualquer tipo de conta. Já estes exigem login com conta claude.ai e ficam fora do alcance de uma chave de API:

- sessões na nuvem e o uso pelo celular;
- app desktop, com exceção parcial: há configurações corporativas que o ligam a outros provedores;
- Remote Control;
- extensão do Chrome;
- Slack, só nos planos Pro, Max e Ultra. Em Team e Enterprise, o caminho para o chat do time é outro produto, o Claude Tag.

A extensão do Chrome pede ainda um plano direto da Anthropic e funciona em Chrome e Edge. A integração não é suportada dentro do WSL.

### Requisitos de sistema da CLI

- macOS 13 ou mais novo; Windows 10 (versão 1809) ou mais novo; Ubuntu 20.04, Debian 10 ou Alpine 3.19 em diante.
- 4 GB de RAM, processador x64 ou ARM64, conexão com a internet.
- Estar num dos [países atendidos](https://www.anthropic.com/supported-countries) pela Anthropic.
- Git é opcional para o Claude Code e indispensável para este curso. No Windows nativo, o Git for Windows é recomendado: com ele o Claude usa Bash; sem ele, usa PowerShell.

### Por que sua versão anda na frente do selo

A instalação nativa se atualiza sozinha, em segundo plano. Instalações por Homebrew e WinGet não: esperam você rodar o comando de atualização. O [M1](../m1/) mostra os dois casos.

</Camada>

<Camada tipo="armadilhas">

### Assinar achando que o plano gratuito serve

A lista de contas aceitas começa no Pro. Confira o nome do plano antes de reservar a tarde para o [M1](../m1/).

### Uma chave de API esquecida no ambiente

Se a variável `ANTHROPIC_API_KEY` existir e você aprovar o uso dela, a CLI usa a chave, mesmo com assinatura ativa. O consumo vai para a conta de API, não para o plano. Dentro da sessão, `/status` mostra qual credencial está valendo. Remover a variável devolve você à assinatura.

### Esperar que o celular rode código

O app do celular é controle remoto. O trabalho acontece na nuvem ou no seu computador ligado.

### Tratar o chat como executor

Pedir ao chat um projeto inteiro e colar arquivo por arquivo funciona até o terceiro arquivo. Depois você vira o mensageiro entre duas janelas. Se há arquivo para mexer, é trabalho do Claude Code.

### Confiar no progresso como se fosse backup

O progresso mora no armazenamento local do navegador. Limpar os dados do site, trocar de navegador ou usar janela anônima zera tudo. A Ficha 2 resolve isso em um minuto.

### Ler o selo como garantia eterna

O selo diz o que era verdade em uma versão e uma data. Um menu pode ter mudado de nome desde então. Divergiu? A documentação oficial e a página [O que mudou](../f/) desempatam.

</Camada>

  objetivo="Conferir conta, terminal, git, Node, GitHub e editor, e marcar sua trilha no mapa."

1. **Conta e plano.** Decida qual dos três acessos você vai usar. Para assinatura, compare os planos em [claude.com/pricing](https://claude.com/pricing) e confirme que o seu é Pro ou superior. Anote o nome do plano: você vai precisar dele no M1.
2. **Terminal.** Abra um. O atalho do seu sistema está no Essencial, na parte sobre o seletor. No Windows, use o PowerShell: o prompt dele começa com `PS C:\`. Se começar só com `C:\`, você abriu o CMD.

3. **Git.** Rode:

   ```bash
   git --version
   ```

   Não tem? Instale por [git-scm.com](https://git-scm.com/downloads), feche o terminal e abra outro.

4. **Node.js.** O laboratório do curso roda em Node 20 ou mais novo:

   ```bash
   node --version
   ```

   Não tem, ou é antigo? Instale a versão LTS de [nodejs.org](https://nodejs.org/en/download).

5. **GitHub.** Crie sua conta em [github.com](https://github.com/signup), ou entre na que já tem. O plano de entrada basta para o curso; as condições vigentes estão em [github.com/pricing](https://github.com/pricing).
6. **Editor.** Qualquer editor de código serve. O curso mostra o VS Code. Se ele já está instalado:

   ```bash
   code --version
   ```

7. **Trilha.** Vá à [página inicial](../), seção "O mapa", e clique na sua trilha. As estações fora dela ficam apagadas no mapa.

<Prova>

```bash
git --version
node --version
```

Os dois comandos respondem com um número de versão, e o do Node começa com `v20` ou mais. Na nossa execução, em Windows 11:

```text
git version 2.55.0.windows.3
v24.19.0
```

Na página inicial, o botão da sua trilha aparece marcado, e continua marcado depois de recarregar a página.

</Prova>

<Gabarito>

Não há resposta única: há um kit completo. Confira os seis itens.

| Item | Pronto quando |
|---|---|
| Conta | Você sabe dizer o nome do plano (ou que vai usar créditos do Console) |
| Terminal | Abre, e você sabe qual é (PowerShell, Terminal, Bash) |
| Git | `git --version` mostra uma versão |
| Node | `node --version` mostra `v20` ou mais |
| GitHub | Você consegue entrar na sua conta pelo navegador |
| Editor | Abre uma pasta e mostra os arquivos |

Na nossa máquina, `code --version` respondeu `1.146.0`. A extensão do Claude Code para VS Code pede a versão 1.94.0 ou mais nova.

</Gabarito>

<DeuErro>

- **"Comando não encontrado" logo depois de instalar.** O terminal aberto antes da instalação não enxerga o programa novo. Feche e abra outro.
- **`node --version` mostra um número abaixo de 20.** Há uma instalação antiga. Instale a LTS atual e confira de novo num terminal novo.
- **A trilha não fica marcada.** O site grava a escolha no armazenamento local do navegador. Janela anônima ou bloqueio de armazenamento impedem isso. O curso funciona igual, só não lembra de você.

</DeuErro>

<Desafio>

Já tem o Claude Code instalado? Rode `claude --version` e compare com o selo desta página (na nossa execução: `2.1.323 (Claude Code)`). Depois rode `claude auth status` e ache dois campos na resposta: `loggedIn` e `authMethod`. Eles dizem se há login e de que tipo.

</Desafio>
