## Rechecagem (13/11/2026, rotina do autor)

Feita ao fim do módulo, antes de fechá-lo:

1. **Tamanho:** a primeira versão tinha 4.841 palavras (Essencial + fichas = 4.182), acima do teto de 3.500 do guia. Reescrito: Essencial 1.935 + fichas 1.401 = 3.336 (3.847 com as camadas).
2. **Compatibilidade com PowerShell 5.1:** todo comando de criação de arquivo da ficha tem `<SO>` com `Set-Content -Encoding ascii`; os JSON de uma linha foram validados com `ConvertFrom-Json` e testados com o `claude -p` de verdade. O script de desvio usa `.mjs` porque o laboratório é ESM (a primeira versão, `.js` com `require`, falhou com `require is not defined`).
3. **Pegadinha do `-p`:** `allow` em `.claude/settings.json` não vale em `-p`; por isso a Ficha 2 usa `settings.local.json`. Descoberto lendo a doc antes de executar.
4. **Teste mal montado:** a primeira tentativa de `cat` e `node` liberados quebrou as aspas do `--allowedTools` no meu auxiliar e foi descartada; refeita com argumentos corretos.
5. Flags, comandos e variáveis citados varridos contra a doc e a CLI (nenhum novo sem ocorrência); HTML sem Markdown solto, ids únicos, 4 fichas, hierarquia de títulos ok; 0 links quebrados; axe ok.
6. Termo unificado: "transcrição" (como no M3), no lugar de "transcrito".
7. Falso alarme descartado: o "v2.1.283" do M3 (Conduzindo no dia a dia) para o modo inicial auto está correto; a v2.1.228/233 da doc é outra condição (disponibilidade).
