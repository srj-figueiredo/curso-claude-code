## Rechecagem (13/11/2026, rotina do autor)

1. **Bug no servidor do laboratório:** respostas fora de ordem por processamento assíncrono concorrente; corrigido com fila (uma mensagem por vez) e retestado.
2. **Bug do `\n`:** a primeira correção gravou quebras reais dentro de uma string; `node --check` pegou; corrigido.
3. **PowerShell 5.1:** o pipe `Get-Content ... | node` antepõe um BOM à primeira linha e o `JSON.parse` falhava (`JSON inválido`). A ficha usa `cmd /c "node ... < arquivo"` na versão Windows (testado: 3 respostas); o servidor do laboratório ganhou tolerância a BOM (testado). Adicionado ao "Deu erro". Também confirmado que o `--` do `claude mcp add` passa intacto pelo PowerShell 5.1.
4. **MDX:** atributo `win="cmd /c \"...\""` quebrou o build (JSX não aceita `\"` em atributo); trocado para aspas simples por fora.
5. **Teste quebrado por mim:** `claude mcp add ... | head -1` encerrou o comando por SIGPIPE antes de gravar; descartado e refeito sem o pipe. Virou aviso no "Deu erro" da Ficha 2.
6. **Flags, comandos e variáveis** varridos contra a doc e a CLI: nenhum do M10 sem ocorrência. HTML sem Markdown solto, ids únicos, 4 fichas, hierarquia ok; 0 links quebrados; axe ok.
7. **Tamanho:** Essencial + fichas = 2.839 palavras.
8. **Privacidade:** `claude mcp list` e as listas de servidores trazem conectores e plugins pessoais do autor; nenhum nome foi copiado para a página.
