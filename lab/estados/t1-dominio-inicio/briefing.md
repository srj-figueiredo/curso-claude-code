# Cliente: Studio Lia (pilates)

Este cliente é fictício, criado para o curso. Endereços e telefones não existem.

## Quem é

A Lia é instrutora de pilates e abriu o Studio Lia há dois anos, com duas salas pequenas. As alunas
marcam aula pelo WhatsApp e ela perde tempo respondendo as mesmas dúvidas: horários, preços e se
dá para fazer uma aula experimental.

## O que ela pediu

Um site de uma página, para celular, com:

1. Nome do studio e uma frase curta de boas-vindas.
2. As turmas e os horários.
3. Os planos e os preços.
4. Um formulário para **agendar a aula experimental** (nome, turma e data), que abra o WhatsApp da Lia
   com a mensagem pronta.
5. Endereço e botão de WhatsApp.
