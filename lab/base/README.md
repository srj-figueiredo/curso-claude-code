# Pendências

Lista de pendências de linha de comando. É o projeto-laboratório do Manual de Bordo do Claude Code:
pequeno o bastante para caber na cabeça, real o bastante para ter testes, arquivo de dados e CLI.

Sem dependências. Precisa só de Node 20 ou mais novo.

```bash
node src/cli.js add "comprar café"
node src/cli.js list
node src/cli.js done 1
npm test
```
